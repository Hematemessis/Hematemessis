我做过 AIGC 广告工作流、游戏 AI Coding Copilot 和游戏智能 Agent 队友（是的，就是没有那么蠢的人机🤖），关注怎样把模型能力接入真实场景。作为非科班出身的小菜鸡，我习惯（只能）先把输入、流程和评价标准定义清楚，再推动产品进入生产与迭代。
